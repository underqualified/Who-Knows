Idle-Gap Test Framework 
​ a verification protocol designed to evaluate endogenous agency in autonomous agent architectures. Derived from the theoretical framework in WHO KNOWS? A Thought Experiment on Intelligence and the Unknown Architecture of Purpose (Beliveau, 2026).
​Overview
​ current benchmarks evaluate artificial agents while actively prompted with external goals. The Idle-Gap Test observes agent behavior during a zero-prompt execution window.
​When a bounded task completes, the next objective is intentionally withheld while leaving the runtime environment, tools, and execution scheduler active.
